# PrismAI 多模态 AI 面试教练

## 运行

双击：

```text
start_prismai.bat
```

Edge 会自动打开：

```text
http://127.0.0.1:8501
```

请保持黑色命令行窗口打开，关闭即停止服务。

首次使用先点「注册」创建账号：

- 用户名 2–32 个字符，不能含空格；
- 密码至少 8 位；
- 注册成功后自动登录。

然后选择题目，上传 WAV 或 MP4/MOV，点击「开始评估」。  
只上传视频时会自动提取音轨；项目内 `sample_speech.wav` 可用于测试。

## 个性化出题

默认题库有 **8 个类别、40 道题**：

```text
行为类 / 技术类 / 情景类 / 项目深挖 /
岗位业务 / 压力追问 / 管理协作 / 动机匹配
```

页面里的「个性化出题（按岗位 / JD 生成）」支持：

- 目标岗位、目标行业；
- 职级 / 经验、面试类型、难度；
- 重点关注（项目、算法、系统设计、协作、领导力、业务、压力等）；
- 粘贴岗位 JD / 面试要求；
- 题目数量 5–10 道。

生成后每道题会附带：

- 类别；
- 难度与标签；
- 一条追问，方便继续深挖。

可以随时切回默认题库，或清除个性化题目。当前使用离线模板生成，
不依赖 Ollama；即使本地 LLM 未启动也能用。

## 功能

- 默认题库 8 类 40 题 + 按岗位/JD 个性化出题；
- 语音 / 内容 / 视觉三路分析，单模态失败自动降级；
- 置信度加权融合、五维雷达、综合评分和改进建议；
- 登录、失败 5 次锁定 5 分钟、60 分钟空闲超时；
- 历史趋势、历史报告详情；
- 左侧栏「系统状态」可查看模型、OpenCV、Ollama、数据库状态。

### 量化评分标准（rubric 2.0）

内容五维各设 **5 个可观察指标**，每项 20 分，命中即得分：

- 逻辑性 22%：回应题意 / 观点明确 / 因果依据 / 分步论证 / 结论呼应
- 深度 24%：量化结果 / 个人贡献 / 情境背景 / 技术业务细节 / 约束取舍
- 结构 20%：开头总起 / 分层展开 / 过程完整 / 结果导向 / 收尾总结
- 表达 14%：句段适中 / 篇幅适中 / 无冗余重复 / 用词具体 / 衔接自然
- 准确度 20%：紧扣题意 / 与资料一致 / 数据可核验 / 无过度断言 / 标注不确定性

规则评分器与 LLM 使用**同一指标清单**（[data/rubric.py](data/rubric.py)），
评估报告展开「查看转写、评分证据与扣分依据」可看到逐指标命中清单
（✅ 命中 / ◐ 部分 / ⬜ 未命中）与对应改进建议。准确度无可核验资料时
固定 50 分，不臆测事实。

### 📞 微信通话式 AI 语音面试

- 点击「开始通话」出现来电界面，点「接听」后**全程免手动操作**：
  AI 面试官语音提问 → 你直接开口回答 → 说完自动停止录音 →
  AI 生成评分反馈并语音追问，直到轮数结束；
- 通话界面含 AI 头像动效、通话计时、录音电平指示、摄像头自拍预览
  （仅本地显示不上传）、🔊 重播与挂断按钮；
- 结束时语音播报整场平均分与改进建议，复盘自动沉淀进知识库（可选），
  页面保留逐轮聊天记录；
- 需要 Chrome / Edge 并允许麦克风；麦克风被拒时可在通话界面重试。

### AI 面试官语音对话（多模态输出）

- 多轮面试开启「AI 面试官语音播报」后，AI 会朗读开场白、每道题目、
  本轮评分反馈与结束语（浏览器原生中文 TTS，可关闭）；
- 用户用麦克风录音回答（或上传视频），AI 根据回答生成针对性追问；
- 每轮回答输出：转写文本 + 五维评分 + 雷达图 + 量化指标命中清单 + 建议；
- 浏览器拦截自动播放时，点页面上的「🔊 播放语音」按钮即可。

### 面试知识库

- 个人背景、项目证据、目标岗位 JD、面试官风格，按账号存于本机 SQLite；
- 内置 **10 个岗位 JD 画像**（后端 / 前端 / 算法 / 数据分析 / 产品 /
  测试 / 运维 / 移动端 / 大数据 / 校招通用），可一键导入 JD 再修改；
- 每场多轮面试结束后自动把**复盘沉淀**（每轮得分与最需提升点）追加进知识库；
- 知识库内容用于生成追问与核对回答，面试官风格不改变固定评分标准。

## 目录

```text
app.py                 Streamlit 入口
core/                  门面、输入归一化、融合、配置、诊断
analyzers/             语音 / 内容 / 视觉分析器
data/                  题库、个性化出题、JD 画像库、提示词库、认证、SQLite 存储
report/                报告构建
ui/                    登录页、微信通话组件（call_static/ 通话界面静态页）
config/                权重与运行配置
.venv/                 Python 3.12 运行环境（不要删）
models/                本地 Whisper 模型（不要删）
prism.db               账号与历史数据（不要删）
requirements.txt       重建环境用
```

## 注意

- 不要直接运行 `python app.py`，必须用 `start_prismai.bat` 或 `streamlit run`；
- 不要删除 `.venv/`、`models/`、`prism.db`；
- 内容维度显示降级时，通常是 Ollama 未启动；运行 `ollama serve` 并准备 `qwen2:1.5b` 后可变为正常；
- 服务默认只监听本机 `127.0.0.1:8501`。
